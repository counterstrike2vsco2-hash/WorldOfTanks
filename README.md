Офлайн-мод для легендарной версии **World of Tanks 0.9.0** (апрель 2014, эпоха первых HD-моделей):
свой локальный сервер, боты, полноценный ангар — игра работает без подключения к серверам
Wargaming/Lesta. Возвращает тот самый вайб 2014 года 🎮

## 🕹 Быстрый старт

1. Скачай клиент World of Tanks **0.9.0** (экспериментальная сборка, уже не распространяется официально)
2. Скачай последний релиз мода из оригинального репозитория
3. Распакуй zip и следуй инструкции внутри (сервер `offline.loc` поднимается локально)
4. В ангаре жми **«В бой!»** — 15v15 с ботами, F9/F10 — доп. меню
