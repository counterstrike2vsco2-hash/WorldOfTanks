# WorldOfTanks — мои эксперименты с оффлайн-модом 0.9.0 🎮

Это **не зеркало** и не чужой контент «как есть». Сюда я складываю **оффлайн-мод
WoToffline0.9.0** и вокруг него делаю **свои эксперименты** — чтобы собрать себе
приятную атмосферу того самого вайба World of Tanks 0.9.0 (2014 год, старый ангар,
кнопка «В бой!», боты вместо онлайна).

## 🕹 Как ставится мод (по файлам автора)

1. Нужен клиент **World of Tanks 0.9.0** (старая сборка 2014 года).
2. Папку `res_mods` из мода — в папку игры.
3. Запустить `install.bat` (нужен **Python 2.7**): он компилирует исходники
   `src/gui_mods/offhangar/*.py` в `.pyc` и копирует всё в `рес_mods` игры.
4. Рядом с `WorldOfTanks.exe` лежит `offline_user.txt` — там настраиваются
   ник, накрутка золота/серебра/свободки, число ботов (до 15v15), модули ботов,
   засвет, награды за обучение и т.д.
5. Запускаешь игру → ангар оффлайн, `offline.loc`, кнопка **«В бой!»**. Клавиши
   **F9** (меню/ресурсы), **F10** (боевое обучение), **K** (выйти из боя).
